## 排查结论汇总

**T 维度的重点（按影响排序，均未修复，供后续按铁律验证后落地）**：

1. **T12 `_link_findings` O(findings×endpoints)** —— 用户 3.67M findings × 数千
   endpoints ≈ 10¹⁰ 元素比较，**report 段分钟级主凶**（与 BUG 62 同型，本次推演
   升级为「结构确定」）。
2. **T8 `mark_params_as_sources` O(Σ接口×全图)** —— 数千接口 × 数百万节点 =
   数十亿循环，接口提取段隐患；同 BUG 62 索引化修法。
3. **T4 状态槽默认白 parse 一遍全库** —— 无条件浪费，改动零风险（默认路径无人消费结果）。
4. **T5 每文件 parse ≥2 遍** —— 结构性冗余，省一遍全库 parse 需 parser 树缓存。
5. **T1/T2 指纹成本** —— 每次扫描必付的全内容 hash + 过期缓存白反序列化。

**FP 维度**：F 类 def-use 遮蔽错配实测 **34.2%** 的 def→use 对是无作用域配对
（`shadow_scope_probe.py`，ureport2）——纯假连通、收窄零漏报代价，从「待量化」
升级为「量级可观」。桥接三机制（E 类）占比实测见上节。

**FN 维度**：N1 receiver 收窄兜底、N2 BFS visited 剪枝、N3 预算截断为已知取舍；
T8 覆盖 source 类别不损召回；无新增高影响 FN。

## 实测验证与认知修正（2026-08-25，ureport2 469 文件）

探针 `benchmarks/taint_explosion_probe.py` + `perf_probes/bfs_edge_audit.py`
+ `perf_probes/fp_quantify.py` + `perf_probes/shadow_scope_probe.py`
+ `perf_probes/phase_timing.py` 在 ureport2 上实测，修正本报告早期推断：

- **每 source 平均达 41.9 个 sink，其中 38 个（90.7%）只在桥接边存在时可达**——
  全移返回值桥接 + 无条件桥接后骤降到 **3.9 个/source**（`fp_quantify.py`）。
  ⇒ 候选爆炸的构成是 **宽模式 sink × 桥接假连通**，两腿缺一不可。
- **全连接兜底（low）对可达性零贡献**——2,041 条边（1.7%）全部冗余，R 移除
  零收缩。修正 E 类早期「全连接兜底是主凶」印象，实际主凶是**返回值桥接**
  （R -35%）+ **无条件桥接 var_ref→call_site**（R -21.5%）。
- **纯桥接 sink 里 ~90% 命中 A/B 宽模式**：`Expression(` 149、`Object(` 39、
  `.execute(` 38、`List(` 33、`.read(` 27、`.parse(` 17（375 个不同 sink）。
- 返回值桥接跨文件错配实锤路径：`BaseServletAction:80 decode(value)` →
  无条件桥接 → decode 函数 → 返回值桥接 → **ExportExcel97ServletAction:78**
  `resp.setHeader(…)`（两个完全不同的 Servlet）。

**由此的收窄方向排序变化**（仍须先证不漏）：全连接兜底可**安全移除**
（不改变任何可达性，纯删冗余边）；返回值桥接/无条件桥接须上下文敏感化
（按调用实例连）而非粗暴移除（否则真实 return 中转场景 FN）。

### T8/T12 在用户项目规模下的推演（结构确定，非实测）

- **T12 `_link_findings` O(findings × endpoints)**：用户 3,675,408 findings ×
  endpoints（7 万文件 Java 数千起）≈ **10¹⁰ 量级列表元素比较**，每元素两次字段
  访问 + 建表。CPython 下 ≈ **10–20 分钟**，是用户「系统没法用」的时间维潜在
  主因之一（与已修的 BUG 62 汇总同型，此处在 report 段）。
- **T8 `mark_params_as_sources` O(Σ接口 × 全图)**：specs = 所有带 handler 的接口
  （含 Spring/Java，`analyzer.py:257-262` 无条件构造）；数千 specs × 数百万图节点
  ≈ **数十亿 Python 级循环**，分钟级。
- **修复 = BUG 62 同型索引化**（零语义影响）：T8 用既有 `_nodes_by_file` 预建
  `(file_path, enclosing_function) → [param ids]`，O(全图一次 + Σspecs×本文件参数)；
  T12 预建 `(file_path, handler) → [eps]` + `file_path → [eps]`，每 finding O(1) 查表。

### F 类遮蔽错配量化（`perf_probes/shadow_scope_probe.py`，ureport2）

函数内 def→use 35,885 对中 **34.2%（12,280）是无作用域错配候选**：内层 def / 外层
use 18.9%（6,799）+ 同深度平行分支 15.3%（5,481）。配对逻辑核实 `dataflow.py:172`
无位置/作用域过滤——每个 def 配同名**全部** use。不是角落场景，是常态比例；
纯假连通、收窄零漏报代价。详见 `docs/误报面清单.md` F 类。
